Envoi des récaps aux parents

1. Contacts des parents

Colonnes du CSV : nageur ; annee ; parent ; telephone ; canal (canal = whatsapp ou sms). Un nageur peut avoir plusieurs lignes (père, mère…). Vous pouvez aussi saisir les numéros directement ci-dessous. 🔒 Les numéros restent dans ce navigateur sur cet ordinateur : rien n'est envoyé sur Internet par cette page.

2. Message

Chaque course est suivie de l'écart par rapport au temps d'engagement : 🟢 + = temps gagné, 🔴 − = temps perdu. WhatsApp ne permet pas de colorer du texte : le bouton 🖼 Image de chaque nageur copie un récap avec les temps écrits en vert / rouge, à coller (Ctrl+V) dans la conversation.

3. Envoi

WhatsApp : s'ouvre (appli ou WhatsApp Web) avec le message déjà rédigé, il reste à appuyer sur « Envoyer ». SMS : à utiliser depuis un téléphone (ou avec « Liaison avec le téléphone » sous Windows). Le bouton ouvre la messagerie avec le message prêt. Un envoi est marqué « ✓ fait » dès que vous cliquez ; vous pouvez l'annuler.
